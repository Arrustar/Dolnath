DOLNATH — INTERACTIVE MAP PAGE

Files:
  map.html              The standalone interactive map page
  new-dolnath-2k.png    Original "New Dolnath 2K.png" map, unchanged

INSTALL ON AN EXISTING WEBSITE
1. Upload map.html and new-dolnath-2k.png into the same directory as your site's index.html.
2. Add a navigation link anywhere in your existing site's HTML:
     <a href="map.html">Explore Map</a>
3. Visit https://your-site.example/map.html

If your site uses a different home-page filename or path, edit the Home link in map.html.
If you put the files in a separate folder, adjust the image src and the Home link accordingly.
No external JavaScript libraries, build steps, APIs, or hosting services are required.
Works with GitHub Pages and ordinary static web hosting.

CONTROLS
- Mouse wheel or trackpad scroll: zoom around cursor
- Click and drag: move the map
- Double-click: zoom in
- + / - buttons: zoom in or out
- Fit map: show the entire map
- Fullscreen: expand the map viewer
- Miniature map at bottom-right: click to jump to a location
- Touchscreen: one finger to pan, two fingers to pinch zoom
- Keyboard (after focusing map): arrows to pan, +/- to zoom, 0 or F to fit
